# Bitácora de dificultades

## Dificultad 1 - Organización inicial

Fecha:
15/10/2026

Problema:
Se debía decidir cómo separar las responsabilidades del sistema.

Causa:
El proyecto incluye diferentes estructuras y dos tipos de usuario.

Solución:
Se organizó el proyecto mediante paquetes:
modelo, estructuras, grafo, árbol, servicio y aplicación.

Decisión:
Mantener la lógica del negocio fuera de la clase Main.

Aprendizaje:
La separación por responsabilidades facilita las pruebas
y el mantenimiento del código.
